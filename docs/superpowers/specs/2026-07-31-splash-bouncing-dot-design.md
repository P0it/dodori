# 스플래시 모션 — i 점이 통통 튀어 안착

날짜: 2026-07-31 · 대상: `src/components/BrandSplash.tsx`

## 목표

첫 로딩 스플래시에 픽사 인트로 같은 짧은 모션을 넣는다. 워드마크 `dodori`의 마지막 `i` 점이
화면 위에서 떨어져 맨 왼쪽 `d`부터 글자 위를 통통 튀며 굴러와, 마지막에 제자리에 안착한다.

## 결정

- **스플래시 워드마크를 로마자 소문자 `dodori`로 되돌린다.** 직전 커밋에서 한글 "도돌이"로 바꿨지만
  점 모션은 로마자 `i`가 있어야 성립한다. 런처 앱 이름(`app.json` `name`)은 "도돌이" 그대로 —
  브랜드 표기 규칙(한글 "도돌이" / 로마자 `dodori`)에 어긋나지 않는다.
- **홉은 5번** — d→o→d→o→r→i, 글자마다 한 번씩 밟고 점점 낮아지는 포물선.
- **점 색은 `color.accent`(브랜드 그린)** — 흰 워드마크 위 그린 점 하나가 마크(𝄆)의 그린과 이어진다.

## 구현

통짜 `<Text>` 대신 **글자 6개를 각각 `<Text>`로 나란히** 렌더한다. 마지막 글자만 점 없는 `ı`(U+0131).
각 글자의 `onLayout`으로 중심 x를 재서 점의 착지 좌표로 쓴다 — 좌표 하드코딩이 없으니 폰트·기기별
글자폭 차이에 깨지지 않는다. 6개가 다 측정되면 그때 시퀀스를 시작한다.

점의 "바닥"은 `i`의 점이 앉을 높이(글자 상단보다 약간 위)로 고정한다. 그 수평선 위를 튀므로
"글자 위에서 통통"으로 읽히고, 마지막 착지점이 곧 정확한 `i` 점 자리가 된다.

`transform`/`opacity`만 쓰므로 전부 `useNativeDriver: true`.

### 타임라인 (총 ~2.0초, 네이티브 스플래시 이후)

| 시각 | 동작 |
|---|---|
| 100ms | 워드마크 `dodorı` 페이드 + 10px 상승 (280ms, out-cubic) — 점 자리는 비어 있음 |
| 380ms | 점이 화면 위(-140px)에서 `d` 위로 낙하 (220ms, in-quad = 가속) |
| 600ms | 홉 5회. 높이 30·22·15·10·6px, 각 190→125ms로 짧아짐. 상승 out-quad / 하강 in-quad, x는 구간마다 linear |
| 1380ms | `i` 자리 안착, 홀드 280ms |
| 1660ms | 전체 페이드아웃 300ms → `onDone()` |

### 눈으로 맞출 상수

`DOT_SIZE`(점 지름)와 `DOT_CY`(점 중심의 세로 위치)는 Pretendard ExtraBold 36px의 실제 `i` 점에
맞춰 실기에서 조정한다. 초기값 5 / 12.

### 폴백

`ı`(U+0131)가 Pretendard에 없어 두부로 뜨면, `dodori`를 그대로 쓰고 `i`의 점 위에 `color.bg`
사각형을 덮어 가린다 (배경이 단색 #121212라 보이지 않는다). 실기 확인 후 필요할 때만.

## 범위 밖
