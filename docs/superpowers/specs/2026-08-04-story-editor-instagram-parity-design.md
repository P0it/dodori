# 스토리 편집기·뷰어 — 인스타 조작 관습 맞추기 (2026-08-04)

## 문제

세 가지가 사용자가 기대하는 동작과 어긋난다.

1. **텍스트 플로우가 두 화면으로 쪼개져 있다.** `T`를 누르면 풀스크린 모달(`TextComposer`)이 뜨고,
   거기서 입력·색·크기를 다 정하고 **완료를 눌러야** 비로소 캔버스 위 스티커가 되어 드래그·핀치가 붙는다.
   "텍스트를 놓고 그 자리에서 조작한다"가 아니라 "입력 모드 → 조작 모드" 왕복이다.
2. **사진 확대·축소가 없다.** 편집 캔버스는 스크롤 폼 안의 4:5 박스에 `contentFit="contain"`이고
   핀치 핸들러가 아예 없다. 모바일 브라우저에서 핀치하면 앱이 아니라 **브라우저 페이지 전체**가 확대된다.
3. **뷰어에서 꾹 눌러도 멈추지 않는다.** 자동 진행은 답장 입력 중에만 멈춘다.

## 결정

- 크롭은 **저장 시 실제로 굽는다** (변환값 저장 아님) — 소비처(뷰어·피드·보관함)를 하나도 안 건드리는 유일한 선택
- 편집 화면은 **풀스크린 9:16 캔버스**
- 인스타 기능 중 **조작 관습만** 맞춘다. 하이라이트·설문/퀴즈/음악 스티커·멘션·링크·외부 공유는 범위 밖

## 1. 편집 화면 구조 (`src/app/modals/create-story.tsx`)

`ScrollView` + 4:5 미리보기 박스를 걷어낸다. 스크롤이 남으면 핀치·팬이 스크롤과 경쟁한다.

- 사진 없음: 검은 화면 중앙에 "오늘 한 컷을 골라주세요"
- 사진 있음: 화면 폭에 맞춘 **9:16 캔버스**가 중앙, `overflow: hidden`
  - 상단 오버레이: 닫기(×) / `T`
  - 하단 오버레이: "…에도 담기" 칩 + 올리기 버튼
  - 텍스트 편집 중에는 상·하단 오버레이가 사라지고 크기 슬라이더·색 팔레트가 대신 뜬다

## 2. 사진 줌 (`src/components/story/StoryCanvas.tsx`, 신규)

- 사진은 캔버스를 **덮는(cover)** 배율에서 시작 — 크롭 최소, 여백 없음
- `Gesture.Simultaneous(Pinch, Pan)`, Reanimated shared value로 `scale`·`tx`·`ty`
- 배율 1~4배(cover 대비). 팬은 **사진이 항상 캔버스를 덮도록** clamp — 검은 여백이 새지 않는다
- 모바일 브라우저 페이지 줌 차단: 캔버스에 `touch-action: none`

## 3. 저장 — 그 프레임 그대로 굽는다

올리기 시 `expo-image-manipulator`로 캔버스에 보이는 영역만 crop → 그 결과를 업로드한다.
(`expo-image-manipulator`는 이미 프로필 크롭에 쓰는 의존성이라 새 의존성이 없다)

캔버스 좌표 → 원본 픽셀 변환은 `src/lib/stories.ts`의 순수 함수로 내리고 단위 테스트를 붙인다.

```
coverScale(photoW, photoH, canvasW, canvasH)  → 캔버스를 덮는 최소 배율
clampPan(...)                                  → 여백이 안 생기는 이동량
cropRect(...)                                  → 원본 픽셀 기준 {originX, originY, width, height}
```

**뷰어·피드·보관함은 손대지 않는다.** 크롭된 사진이 곧 캔버스이므로 텍스트의 0~1 좌표가 그대로 유효하고,
기존 스토리(원본 비율 + 그 기준 좌표)도 지금의 `containedRect` 로직으로 계속 맞는다.

## 4. 텍스트 인라인 편집 (`src/components/story/StoryTextInput.tsx`, 신규)

`TextComposer.tsx`는 폐기한다.

- `T` 탭 → **그 순간 오버레이를 만들고**(중앙·기본색·기본크기) 곧바로 그 자리에서 `TextInput`이 커서를 받는다
- 편집 중: 사진은 딤만 깔린 채 그대로 보이고, 왼쪽 크기 슬라이더 · 하단 색 팔레트가 뜬다
- **딤을 탭하면 편집 종료** → 즉시 그 자리에서 드래그·핀치·회전 (`StoryTextEditor` 그대로)
- 스티커 탭 → 다시 인라인 편집. 내용이 비면 그 오버레이는 자동으로 사라진다
- 편집 중에는 키보드를 피해 텍스트가 캔버스 위쪽에 뜨고, 끝내면 원래 자리로 돌아간다
  (인스타와 같은 타협 — 키보드가 올라온 동안에는 드래그가 안 된다)

## 5. 뷰어 — 꾹 눌러 일시정지 (`src/app/story/[id].tsx`)

- 사진 위를 **길게 누르면 정지**하고 상·하단 UI가 사라진다(사진만 남는다). 떼면 이어서 재개
- **재개는 이어서** — 현재 코드는 `paused`가 바뀔 때마다 진행률이 0으로 리셋되는 버그가 있다.
  경과 시간을 보존하도록 고친다
- 좌/우 탭 이동 영역을 화면 전면으로 넓힌다(상단 헤더·하단 입력 줄 제외)

범위 밖(하지 않음): 하이라이트, 설문·퀴즈·음악·멘션·링크 스티커, 사람 간 가로 스와이프, 외부 공유·저장.
